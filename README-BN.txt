মসজিদ পূর্ণাঙ্গ হিসাব — প্রাথমিক PWA সংস্করণ

ফাইলসমূহ:
- index.html: মূল অ্যাপ
- manifest.json: PWA ইনস্টল তথ্য
- sw.js: অফলাইন ক্যাশ
- icon-192.png / icon-512.png: অ্যাপ আইকন

GitHub Pages-এ প্রকাশ:
1. একটি নতুন GitHub repository তৈরি করুন (পুরোনো কৃষি অ্যাপের repository-তে ফাইল মিশিয়ে দেবেন না)।
2. এই ফোল্ডারের ভেতরের সব ফাইল repository root-এ আপলোড করুন।
3. Settings > Pages থেকে Deploy from branch / main / root চালু করুন।
4. HTTPS GitHub Pages URL খুলুন; Chrome menu > Install app / Add to Home screen বেছে নিন।

ডেটা ও ব্যাকআপ:
- ডেটা ব্রাউজারের localStorage-এ থাকে; পরিবর্তনের পর IndexedDB-তে লোকাল snapshot রাখার চেষ্টা করে।
- Backup পেজ থেকে JSON ডাউনলোড করুন এবং অন্য ডিভাইস/ক্লাউডে কপি রাখুন।
- Restore করলে বর্তমান ডেটা প্রতিস্থাপিত হয়; আগে বর্তমান ডেটা ডাউনলোড করে রাখুন।
- Google Sheets ক্লাউড ব্যাকআপের জন্য ZIP-এর `Google-Apps-Script.gs` ব্যবহার করুন।
- Google Apps Script-এ ফাইলের কোড পেস্ট করুন; `SECRET_KEY`-এর জায়গায় ৩২+ অক্ষরের অনন্য গোপন কী বসান।
- Deploy > New deployment > Web app নির্বাচন করুন; Execute as: Me, Who has access: Anyone নির্বাচন করে Deploy করুন এবং অনুমতি দিন।
- Web App URL এবং একই গোপন কী অ্যাপের ব্যাকআপ > Google Sheets ক্লাউড ব্যাকআপ অংশে বসিয়ে “সংযোগ সেটিংস সংরক্ষণ” করুন।
- প্রথমবার ব্যাকআপ পাঠালে আপনার Google Drive-এ “মসজিদ হিসাব — ক্লাউড ব্যাকআপ” নামে একটি Spreadsheet তৈরি হবে।
- “এখনই ক্লাউড ব্যাকআপ” ম্যানুয়াল কপি তৈরি করে; চাইলে স্বয়ংক্রিয় ব্যাকআপ চেকবক্স চালু করুন। সর্বশেষ কপি “সর্বশেষ ক্লাউড ব্যাকআপ ফিরিয়ে আনুন” দিয়ে ফিরিয়ে আনা যাবে। সর্বশেষ ১০টি ব্যাকআপ রাখা হয়।
- গোপন কী কাউকে দেবেন না। Apps Script Web App-এর URL ও কী অ্যাপের সেটিংসে এই ডিভাইসের localStorage-এ থাকে। Google Sheet-এর শেয়ারিং সীমিত রাখুন।
- ইন্টারনেট না থাকলে ক্লাউড ব্যাকআপ হবে না। গুরুত্বপূর্ণ হিসাবের জন্য JSON ব্যাকআপও আলাদা করে ডাউনলোড করে রাখুন।

সতর্কতা:
- এটি প্রাথমিক সংস্করণ। বাস্তব আর্থিক হিসাব ব্যবহারের আগে নমুনা ডেটা দিয়ে সব ফিচার পরীক্ষা করুন।
- হাদিয়া জমা নগদ হিসাবে রেকর্ড হয়; ব্যাংকে জমা হলে লেনদেনের account পরিবর্তন/হিসাব যাচাই করুন।
- নগদ থেকে ব্যাংক স্থানান্তরের জন্য আলাদা transfer feature পরবর্তী সংস্করণে যোগ করা উচিত।
- সদস্য মুছলে সদস্যের পুরোনো payment record থেকে যেতে পারে; ডেটা মুছার আগে ব্যাকআপ নিন।


আপডেট: ব্যয়ের খাতে এখন আলাদা “ইমাম বেতন” ও “মুয়াজ্জিন বেতন” রয়েছে। মাসিক রিপোর্টে নির্বাচিত মাসের ইমাম বেতন, মুয়াজ্জিন বেতন এবং মোট বেতনের সারসংক্ষেপ দেখা যাবে।


ক্লাউড ব্যাকআপ আপডেট: Google Sheets-এ ম্যানুয়াল/ঐচ্ছিক স্বয়ংক্রিয় ব্যাকআপ এবং সর্বশেষ ব্যাকআপ পুনরুদ্ধারের ব্যবস্থা যুক্ত। Apps Script Web App একবার ব্যবহারকারীকে সেটআপ ও Deploy করতে হবে।


যদি অ্যাপে “Google Sheets ক্লাউড ব্যাকআপ” অংশ না দেখা যায়
- নিশ্চিত করুন GitHub Pages যে ফোল্ডার/ব্রাঞ্চ থেকে চালু, ঠিক সেই জায়গায় ZIP-এর masjid-hisab-pwa ফোল্ডারের ভেতরের সব ফাইল আপডেট করেছেন।
- index.html, manifest.json, sw.js, icon-192.png, icon-512.png এবং Google-Apps-Script.gs ফাইলগুলো রাখুন। Google-Apps-Script.gs শুধু Google Apps Script প্রজেক্টে কপি করতে হবে; এটি সাইটের root-এ থাকলেই ক্লাউড সংযোগ হবে না।
- GitHub commit/publish শেষ হলে অ্যাপটি বন্ধ করে আবার খুলুন। Android Chrome-এ সাইটের জন্য পুরোনো cache/site data পরিষ্কার করে পুনরায় লোড করলেও পুরোনো সংস্করণ দূর হতে পারে। নতুন sw.js-তে cache version বাড়ানো হয়েছে।
