মসজিদ পূর্ণাঙ্গ হিসাব — প্রাথমিক PWA সংস্করণ

ফাইলসমূহ:
- index.html: মূল অ্যাপ
- manifest.json: PWA ইনস্টল তথ্য
- sw.js: অফলাইন ক্যাশ
- icon-192.png / icon-512.png: অ্যাপ আইকন

GitHub Pages-এ প্রকাশ:
1. একটি নতুন GitHub repository তৈরি করুন (পুরোনো কৃষি অ্যাপের repository-তে ফাইল মিশিয়ে দেবেন না)।
2. এই ফোল্ডারের ভেতরের সব ফাইল repository root-এ আপলোড করুন।
3. Settings > Pages থেকে Deploy from branch / main / root চালু করুন।
4. HTTPS GitHub Pages URL খুলুন; Chrome menu > Install app / Add to Home screen বেছে নিন।

ডেটা ও ব্যাকআপ:
- ডেটা ব্রাউজারের localStorage-এ থাকে; পরিবর্তনের পর IndexedDB-তে লোকাল snapshot রাখার চেষ্টা করে।
- Backup পেজ থেকে JSON ডাউনলোড করুন এবং অন্য ডিভাইস/ক্লাউডে কপি রাখুন।
- Restore করলে বর্তমান ডেটা প্রতিস্থাপিত হয়; আগে বর্তমান ডেটা ডাউনলোড করে রাখুন।
- স্বয়ংক্রিয় ক্লাউড আপলোড এই সংস্করণে সংযুক্ত নয়। Google Drive/OneDrive/Dropbox-এর OAuth ও অনুমতি/সংযোগ আলাদাভাবে সেটআপ করতে হবে।

সতর্কতা:
- এটি প্রাথমিক সংস্করণ। বাস্তব আর্থিক হিসাব ব্যবহারের আগে নমুনা ডেটা দিয়ে সব ফিচার পরীক্ষা করুন।
- হাদিয়া জমা নগদ হিসাবে রেকর্ড হয়; ব্যাংকে জমা হলে লেনদেনের account পরিবর্তন/হিসাব যাচাই করুন।
- নগদ থেকে ব্যাংক স্থানান্তরের জন্য আলাদা transfer feature পরবর্তী সংস্করণে যোগ করা উচিত।
- সদস্য মুছলে সদস্যের পুরোনো payment record থেকে যেতে পারে; ডেটা মুছার আগে ব্যাকআপ নিন।
